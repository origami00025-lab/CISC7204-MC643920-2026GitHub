# CISC7204 Assignment 02 Module 04  Lab 03
LU MENGJIE MC643920

From this folder run `python -m pip install -r requirements.txt`, then `python app.py`. Open http://127.0.0.1:8050 in your browser. Stop with Ctrl+C. Set PORT to use a different local port. Data are included in data/; no API key or download is needed at runtime.

The app and callback functions implement the supplied course screenshots. Invalid or unavailable selections return an explanatory empty figure. Missing airline delay observations are excluded from means rather than imputed as zero. The course airline extract is a sample, not the complete US aviation population; its flights field is summed as instructed.

Dataset source: see the accompanying course data manifest. The automobile sales dataset is synthetic for teaching; these plots do not establish causal effects. Optional practice variants, where present, are separate scripts and use the same local dataset.
